# 01-product — 제품 정의

## 제품 목표

> **"지금 누가 뭐 해?"** 라는 질문이 팀에서 사라지게 만든다.

팀 업무를 한 화면에서 시각화해, 누가 무엇을 언제까지 하는지 묻지 않아도 알 수 있는 상태를 만든다.

---

## 타겟 페르소나

| 항목 | 내용 |
|------|------|
| **대상** | 10명 규모 스타트업의 팀 리더 |
| **연령대** | 30~40대 |
| **상황** | 슬랙·노션·스프레드시트가 분산돼 있고, 진행 상황을 파악하려면 매번 개별 확인이 필요함 |
| **핵심 니즈** | 한 화면에서 팀 전체 업무 현황을 파악하고, 병목을 즉시 감지하고 싶다 |

---

## MVP 범위

### CRUD 4종 — 모든 동작이 화면에서 이루어진다

| 동작 | 설명 |
|------|------|
| **추가** | 태스크 생성 폼 (제목·상태·담당자·due_at) |
| **목록** | 전체 태스크 리스트 조회 |
| **수정** | 인라인 또는 모달에서 필드 편집 |
| **삭제** | 확인 후 즉시 제거 |

페이지 이동 없이 단일 화면 안에서 4종이 모두 동작한다.

### 상태 분류

| 상태 값 | 의미 |
|---------|------|
| `todo` | 시작 전 |
| `in_progress` | 진행 중 |
| `done` | 완료 |

### 마감 시각 (`due_at`)

- 날짜 + 시간 단위로 지정한다 — `2026-05-12 18:00`
- 날짜만 입력은 허용하지 않는다 (시간 생략 시 기본값 `23:59` 자동 적용)
- 화면에는 `YYYY-MM-DD HH:mm` 형식으로 표시한다

### 라이트 / 다크 테마 토글

- `localStorage`에 선택값을 저장한다
- 새로고침 후에도 마지막 선택이 유지된다
- 시스템 기본 설정(`prefers-color-scheme`) 감지 후 초기값 적용

### 모바일 반응형

- 최소 지원 뷰포트: **360px**
- 360px에서 레이아웃이 깨지지 않고, 모든 CRUD 동작이 가능해야 한다
- 터치 타겟 최소 크기: 44×44px

## UI 톤 — macOS 스타일

| 요소 | 적용 방식 |
|------|----------|
| **모서리** | `border-radius: 12px` 이상의 둥근 처리 |
| **그림자** | 얕고 부드러운 다층 그림자 (`box-shadow` layered) |
| **카드 배경** | 반투명 (`backdrop-filter: blur` + `rgba` 배경) |
| **폰트** | 시스템 폰트 스택 — `-apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif` |
| **전반적 느낌** | 가볍고 깔끔함. 정보 밀도보다 가독성 우선 |

## 확장 로드맵 (MVP 이후)

아래 기능은 MVP 완료 후 단계적으로 추가한다. 현재 아키텍처 설계 시 확장 가능성을 고려하되, MVP에서 구현하지 않는다.

| 기능 | 설명 |
|------|------|
| **JWT 로그인** | 이메일/비밀번호 인증, 역할(admin/member) 분리 |
| **팀 관리** | 워크스페이스·멤버 초대·권한 설정 |
| **Kanban 보드** | 상태별 컬럼 드래그앤드롭 |
| **채팅** | 태스크 단위 댓글·멘션 |
| **CI/CD 연동** | GitHub Actions 빌드 상태 표시 |

---

## 범위 밖 (Out of Scope)

| 항목 | 사유 |
|------|------|
| 외부 결제·구독 | 수익 모델 미확정 |
| 모바일 네이티브 앱 | 웹 반응형으로 대체 |
| WebRTC (영상·음성) | 복잡도 대비 MVP 가치 낮음 |
| 외부 캘린더 연동 | Google·Outlook API 의존성 증가 |
| 파일 업로드 | 스토리지 인프라 미준비 |
| WebSocket | **MVP는 폴링으로 대체**. 실시간 기능은 확장 단계에서 도입 |

## 성공 기준

MVP는 아래 조건을 **모두** 충족할 때 완료로 간주한다.

| 기준 | 측정 방법 |
|------|----------|
| 새로고침 후 상태 유지 | 테마·태스크 목록이 reload 후에도 그대로 |
| 360px 레이아웃 무결 | Chrome DevTools 360px 뷰포트에서 가로 스크롤 없음 |
| API 응답 200ms 이내 | CRUD 각 엔드포인트 p95 기준 |
| CRUD 4종 화면 동작 | 추가·목록·수정·삭제가 페이지 이동 없이 완료 |
| 테마 토글 작동 | 라이트↔다크 전환 후 새로고침해도 유지 |
